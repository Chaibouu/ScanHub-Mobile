Installer l'application

  1. 1

    Télécharger l'APK

    Depuis le téléphone, appuyez sur le bouton orange ci-dessus.

  2. 2

    Autoriser l'installation

    Ouvrez le fichier téléchargé. Android demande d'autoriser l'installation depuis votre navigateur : acceptez pour cette fois.

  3. 3

    Activer le téléphone

    Saisissez le code d'activation donné par votre administrateur (tableau de bord, rubrique « Terminaux mobiles »), puis connectez-vous avec votre compte agent.

ℹ️ L'application n'est pas encore sur le Play Store : c'est pourquoi Android affiche un avertissement. Téléchargez-la uniquement depuis cette page.

Ce que fait l'application

Scan instantané

Le passage est vérifié et enregistré dès que le QR code est lu, avec un verdict en plein écran : vert, orange ou rouge.

Même sans réseau

La liste des billets est gardée sur le téléphone. Les entrées sont envoyées au serveur dès que la connexion revient.

Une seule entrée par billet

Un billet ne passe qu'une fois, même scanné au même moment à deux portes différentes.
